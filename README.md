# Day 30 — 4-week home calisthenics tracker

Installable PWA (works offline) for a 4-week beginner home calisthenics plan with a left-shoulder rehab focus.

- **Today**: warm-up checklist, animated exercise cards, set tracking, weekly rep targets, rest timer, cardio circuit interval timer, shoulder pain / steps / notes check-in.
- **Plan**: 28-day calendar (A/B/A, B/A/B pattern), start date, push-up level, nutrition targets, goals, rules, progressions.
- **Moves**: animated library of every exercise with cues.
- **Progress**: weight chart (goal 74–75 kg), waist, pain log, weekly summary, backup / import.

Plain HTML/CSS/JS, no build step. Data is stored in `localStorage` on the device.
